# GBU Campus

One website for a model-based university visit and fictional single-player haunted-campus game. The default / route is the daytime tour; /night/ enters After the Last Bell. Shared same-tab navigation makes both modes part of one product. Each mode loads only its own scene, controls and audio.

The 2026-10-02 rebuild uses one shared campus layout in both modes: balcony towers, stepped tower, louvered teaching blocks, central crescent/garden/water court, rear arcade, sports hall/track and orange-recessed dormitories. Day offers six landmark visits and a walking route. Night offers water reflection, corridor listening, a timed track lap and a dormitory melody, with zombies, blood, a photographic shoe kick, crawling reassembly, demo and shutdown behavior. Keep local fonts/assets, desktop and emulated touch support, and existing performance defaults.

Physical-model views control relative placement; the organized campus photo set informs facade details. Scale is compressed for play; interiors, dimensions, unseen elevations and the night story are interpreted. This is not an official or surveyed campus reconstruction.

The canonical combined source is this Campus_Experience directory. Refined_Tour and Haunted_Campus are retained source snapshots for provenance; future combined-site edits belong here. Deployment uses only release/, containing a built static site and dependency-free server. No course documents, QA recordings, credentials or node_modules are uploaded.
