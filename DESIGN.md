# GBU Campus interface continuity

The existing campus scene leads. A shared GBU Campus wordmark and same-tab Day tour / Haunted night navigation identify one website. No extra landing page interrupts entry. Night's After the Last Bell title and daytime's architectural welcome remain distinct mode introductions.

Retain locally hosted Newsreader for existing display headings and DM Sans for controls. Day navigation uses the accepted warm paper and charcoal-green palette; night uses deep blue-green and ivory with amber state accents. Active mode is shown with weight, fill, underline and aria-current, not color alone.

The navigation occupies one header row on desktop. On phones it takes a dedicated second row, with objectives and location labels shifted below it. Links provide at least44px touch targets and visible keyboard focus. Pause/end links remain reachable inside the night dialog focus trap.

Only one route's renderer and audio are loaded at a time. Normal browser navigation changes modes and disposes outgoing audio. Browser Back can restore a paused mode but cannot restart sound without interaction.

Visual authority: the existing tour and haunted game sources copied into this project, plus integration-1 desktop/phone captures. This is an extension of their incumbent design, not a new visual identity. The 2026-10-02 rebuild adds a generated photographic trouser leg and running-shoe cutout. Its prompt, alpha validation and source/copy hash are in artifacts/kick-asset-evidence.md. Building geometry is rebuilt from physical-model relationships and facade photos; shared/campus-layout.js is the spatial authority. Night objectives, map and HUD use the same locations.
